# Yacc / Bison Cheat Sheet

## File Structure

```yacc
%{
  /* C code: includes, prototypes, global variables */
  #include <stdio.h>
  #include <stdlib.h>
  int yylex(void);
  void yyerror(char *s);
%}

/* Declarations: tokens, precedence, types */
%token NUMBER ID
%left '+' '-'
%left '*' '/'

%%

/* Grammar Rules: LHS : RHS { C action } ; */
input:
      expr '\n'       { printf("Result = %d\n", $1); return 0; }
    ;

expr:
      expr '+' expr   { $$ = $1 + $3; }
    | NUMBER          { $$ = $1; }
    ;

%%

/* C code: main(), yyerror() */
void yyerror(char *s) {
    printf("Syntax Error: %s\n", s);
}

int main() {
    yyparse();
    return 0;
}
```

---

## Core Declarations

| Directive | Purpose | Example |
|---|---|---|
| `%token` | Declares terminal symbols returned by Lex | `%token NUMBER ID IF ELSE` |
| `%left` | Left-associative operator | `%left '+' '-'` |
| `%right` | Right-associative operator | `%right '='` or `%right UMINUS` |
| `%nonassoc` | Non-chainable operator (e.g. `a < b < c` is invalid) | `%nonassoc '<' '>' LE GE` |
| `%type` | Declares the type of a non-terminal (used with `%union`) | `%type <val> expr term` |
| `%union` | Defines multiple data types for `yylval` and `$$` | `%union { int num; char *str; }` |
| `%start` | Specifies start symbol (default is the first rule) | `%start input` |
| `%prec` | Overrides precedence of a rule with a token's precedence | `'-' expr %prec UMINUS` |

---

## Pseudo-Variables (`$$`, `$1`, `$2`, ...)

| Variable | Meaning | Example |
|---|---|---|
| `$$` | Semantic value of the Left-Hand Side (LHS) | `expr: ... { $$ = ...; }` |
| `$1` | Value of the 1st symbol on the Right-Hand Side (RHS) | `expr '+' expr { $$ = $1 + $3; }` |
| `$2` | Value of the 2nd symbol on the RHS | `'+'` in `expr '+' expr` |
| `$3` | Value of the 3rd symbol on the RHS | 2nd `expr` in `expr '+' expr` |
| `$$ = $1` | **Default action** if no action block is specified | `term: factor ;` implicitly does `$$ = $1` |

```yacc
expr:
      expr '+' expr   { $$ = $1 + $3; }   /* $1 = 1st expr, $2 = '+', $3 = 2nd expr */
    | '(' expr ')'    { $$ = $2; }        /* $2 is the value inside parentheses */
    | NUMBER          { $$ = $1; }        /* $1 is token value from lexer */
    ;
```

## Operator Precedence & Associativity

1. **Precedence order**: Lines defined **lower down** have **higher precedence**.
2. **Associativity**:
   - `%left`: Evaluates left-to-right (`a - b - c` $\to$ `(a - b) - c`).
   - `%right`: Evaluates right-to-left (`a = b = c` $\to$ `a = (b = c)`).

```yacc
%left '+' '-'           /* lowest precedence */
%left '*' '/' '%'       /* higher precedence than + and - */
%right UMINUS           /* highest precedence (unary minus) */
```

### Unary Minus Pattern (`%prec`):
```yacc
expr:
      expr '-' expr           { $$ = $1 - $3; }
    | '-' expr %prec UMINUS   { $$ = -$2; }
    ;
```

## `yy` Variables & Functions

| Name | Type / Kind | What it does |
|---|---|---|
| `yyparse()` | `int` function | Runs the parser. Returns `0` on success, `1` on error. Call from `main()`. |
| `yylex()` | `int` function | Called by `yyparse()` to fetch the next token integer code. |
| `yyerror(char *s)` | `void` function | Called automatically by `yyparse()` upon encountering a syntax error. |
| `yylval` | Global variable | Carries the semantic value of a token from Lex to Yacc. Default type: `int`. |
| `YYACCEPT` | Macro | Immediately exits `yyparse()` returning `0` (successful parse). |
| `YYABORT` | Macro | Immediately exits `yyparse()` returning `1` (parse failure). |
| `yychar` | `int` | Stores current lookahead token code. |

## How Lex and Yacc Work Together

```
          +-------------+  Tokens (NUMBER, '+')  +-------------+
Input --->| Lexer (.l)  |----------------------->| Parser (.y) |
          +-------------+    yylval (42, 10)     +-------------+
                 ^                                      |
                 |-------- includes "y.tab.h" ----------|
```

### 1. In `lexer.l`:
```lex
%{
#include "y.tab.h"      /* Token definitions generated by yacc -d */
%}

%%
[0-9]+      { yylval = atoi(yytext); return NUMBER; }
[a-zA-Z_]+  { return ID; }
[+\-*/()]   { return yytext[0]; }
\n          { return '\n'; }
[ \t]       ;           /* skip whitespace */
.           { return yytext[0]; }
%%
int yywrap() { return 1; }
```

### 2. In `parser.y`:
```yacc
%token NUMBER ID
%%
/* grammar rules using NUMBER, ID */
```

## Common Grammar Patterns (Copy-Paste)

### 1. Arithmetic Expression Recognizer
```yacc
%token ID NUM
%left '+' '-'
%left '*' '/'
%left '(' ')'

%%
input:
      expr '\n'       { printf("Valid Expression\n"); return 0; }
    ;

expr:
      expr '+' expr
    | expr '-' expr
    | expr '*' expr
    | expr '/' expr
    | '(' expr ')'
    | ID
    | NUM
    ;
%%
```

### 2. Full Calculator (with Evaluation)
```yacc
%token NUMBER
%left '+' '-'
%left '*' '/' '%'

%%
input:
      expr '\n'       { printf("Result = %d\n", $1); return 0; }
    ;

expr:
      expr '+' expr   { $$ = $1 + $3; }
    | expr '-' expr   { $$ = $1 - $3; }
    | expr '*' expr   { $$ = $1 * $3; }
    | expr '/' expr   { $$ = $1 / $3; }
    | expr '%' expr   { $$ = $1 % $3; }
    | '(' expr ')'    { $$ = $2; }
    | NUMBER          { $$ = $1; }
    ;
%%
```

### 3. Identifier Validator
```yacc
%token ID

%%
input:
      ID '\n'         { printf("Valid Identifier\n"); return 0; }
    ;
%%
```

### 4. Language Constructs: $a^n b$ ($n \ge 10$ or similar)
```yacc
%%
input:
      S '\n'          { printf("Valid String\n"); return 0; }
    ;

S:
      'a' S 'b'
    | /* epsilon */
    ;
%%
```

## Conflict Resolution

| Conflict Type | What Happens By Default | Solution |
|---|---|---|
| **Shift / Reduce** | Yacc **shifts** by default | Specify operator precedence (`%left`, `%right`) |
| **Reduce / Reduce** | Yacc uses the **first rule listed** in `.y` file | Fix ambiguous grammar rules |

### Classic Dangling-Else Resolution:
```yacc
%nonassoc LOWER_THAN_ELSE
%nonassoc ELSE

%%
stmt:
      IF '(' expr ')' stmt %prec LOWER_THAN_ELSE
    | IF '(' expr ')' stmt ELSE stmt
    ;
```

## Compile & Run

```bash
yacc -d parser.y        # generates y.tab.c and y.tab.h (-d creates the header)
lex lexer.l             # generates lex.yy.c
gcc y.tab.c lex.yy.c -ll
./a.out
```
